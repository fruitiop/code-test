# 抛体运动模拟 (Projectile Motion Simulation)

一个基于 Python 的物理模拟项目，用于对比**理想抛体运动**（无空气阻力）与**实际抛体运动**（含空气阻力）的差异，并进行能量分析。

---

## 一、解决什么问题

在高中和大学物理中，抛体运动通常只在**无空气阻力**的理想条件下讨论，此时轨迹为标准抛物线，射程在 45° 时最大。

但在真实环境中，物体运动时不可避免地会受到**空气阻力**的影响，导致：
- 射程显著缩短
- 最佳发射角度小于 45°
- 机械能被耗散（转化为热能）

本项目通过数值模拟，直观展示空气阻力（线性模型与二次模型）对抛体运动的影响，并对比能量守恒与能量耗散的过程。

---

## 二、功能特性

| 功能 | 说明 |
|------|------|
| **三种运动模型** | 理想情况、线性空气阻力、二次空气阻力 |
| **轨迹对比图** | 三种情况下的运动轨迹、高度-时间曲线、速度-时间曲线 |
| **射程-角度分析** | 计算 15°~85° 不同发射角度的射程，找出最佳角度 |
| **能量分析** | 绘制动能、势能、总机械能随时间变化的曲线，并计算能量耗散比例 |
| **中文支持** | 完整的简体中文图表标注与终端输出 |
| **图片导出** | 自动保存 PNG 图片到本地 |

## 五、使用方法

### 1. 直接运行（保存图片）

```bash
python3 projectile_motion.py
```

程序会自动计算并保存以下图片到当前目录：
- `projectile_motion_comparison.png` — 轨迹、高度、速度对比与结果表格
- `range_vs_angle.png` — 射程与发射角度的关系曲线
- `energy_analysis.png` — 动能、势能、机械能分析

### 2. 弹窗查看图表

```bash
python3 projectile_motion.py --show
```

加上 `--show` 参数后，程序会在保存图片的同时弹出图表窗口（关闭窗口后程序结束）。

### 3. 修改物理参数

目前参数通过修改代码顶部的变量来调整：

```python
# ==================== 物理参数设置 ====================
g = 9.8              # 重力加速度 (m/s²)
m = 1.0              # 物体质量 (kg)
v0 = 50.0            # 初速度 (m/s)
theta_deg = 45.0     # 发射角度 (度)
k_linear = 0.5       # 线性空气阻力系数 (kg/s)
k_quadratic = 0.01   # 二次空气阻力系数 (kg/m)
```

修改后保存，再次运行即可看到新的模拟结果。

## 六、物理模型说明

### 1. 理想情况（无空气阻力）

**解析解：**
- x(t) = v₀·cos(θ)·t
- y(t) = v₀·sin(θ)·t − ½gt²

**特征：** 机械能守恒，射程最大，轨迹为完美抛物线。

### 2. 线性空气阻力

**阻力公式：** F_d = −k·v

**适用场景：** 低速、小雷诺数（如小球在黏性流体中）。

**运动方程（数值解）：**
- dvx/dt = −(k/m)·vx
- dvy/dt = −g − (k/m)·vy

### 3. 二次空气阻力

**阻力公式：** F_d = −k·v²

**适用场景：** 高速、大雷诺数（如炮弹、棒球在空气中的运动），更接近真实情况。

**运动方程（数值解）：**
- dvx/dt = −(k/m)·v·vx
- dvy/dt = −g − (k/m)·v·vy

所有含阻力的情况均采用**欧拉法**进行数值积分求解。
